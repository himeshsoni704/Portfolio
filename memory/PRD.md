## Architecture
- Frontend: CRA + TS + Tailwind + framer-motion + Three.js. `src/App.tsx` (starts at login; BootScreen used by World 2), `src/BootLogin.tsx` (BootScreen default + Win7 LoginScreen named), `src/Site.tsx` (World 1 flow + RockyChat + exitedRef guard), `src/sections/` (Hero, Interests, Exploring, SpaceTransition + SpaceScene, Contact/About/Projects/Research/Experiments/Photography/Journey/PixelatorApp — several intentionally unmounted), `src/win/` (AeroWindow, icons, ui, RockyChat), `src/world/` (World2 phase machine boot/login/desktop/logout, WinManager glass frames, Explorer, apps: ResumeApp/ContactApp/Timeline/Skills/Settings, fs.ts), `src/data/` + `src/lib/site.ts` (single source of real links/facts).
- Backend: `/api/rocky` (Emergent universal key → OpenAI gpt-5.4 Rocky persona, demo fallback, Mongo logs — knows real contact info), `/api/pixelate` (Pillow + numpy + scikit-image SLIC + scikit-learn KMeans).
